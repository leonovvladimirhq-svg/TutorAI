# Архив документов

Устаревшие документы — для истории. **Не использовать как инструкцию**: актуальное — в
корневом [README.md](../../README.md) и в [docs/](..).

| Файл | Что это | Почему в архиве |
|---|---|---|
| `CLOUD.md` | Описание инфраструктуры и статус деплоя (июль 2026) | Описывает Telegram-бота на aiogram и роли по Telegram ID; IP и параметры VM устарели. Актуально: [SERVICES.md](../SERVICES.md), [RESTORE.md](../RESTORE.md) |
| `DEPLOY.md` | Инструкция деплоя (июнь–июль 2026) | Telegram, long-polling, без кодов доступа и вебхука. Актуально: [RESTORE.md](../RESTORE.md) |
| `TutorAI_План_реализации.md` / `.docx` | Исходный продуктовый план (июнь 2026): цели, сценарии, архитектура, KPI | Проектный документ стартовой фазы; продукт ушёл дальше (MAX, модуль наставника). `.md` — исходник, `.docx` — та же версия для передачи |
| `cloud-init-v1.yaml`, `deploy_yc-v1.sh` | Создание первой VM (июнь 2026) | Без пользователя и SSH-ключа в cloud-init — на этих образах так в VM потом не зайти. Актуальный user-data — [deploy/user-data.yaml](../../deploy/user-data.yaml) |

Отложенная ветка разработки (Qwen 3.6 + авторизация Api-Key, 30.06.2026) сохранена тегом
`archive/qwen3.6-apikey-2026-06-30` — см. [DECISIONS.md](../DECISIONS.md).
